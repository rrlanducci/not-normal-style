# Not Normal Style

A local starter website for Not Normal Style, Personal Image Consulting by Camila Rades.

## Open it

Open `index.html` in a web browser.

## Edit it

- Content and sections: `index.html`
- Colours, typography and layout: `css/styles.css`
- Mobile menu and current year: `js/main.js`
- Future photographs: `images/`

## Important before publishing

1. Replace `hello@example.com` in `index.html` with the real business email.
2. Review and approve all service descriptions.
3. Add the final approved prices to the Investment section.
4. Add original or properly licensed photographs.
5. Review privacy and contact-form requirements before adding data collection.

## Save the first Git checkpoint

```bash
git add .
git commit -m "Create initial website prototype"
```

The Google fonts are loaded from the internet. If you open the site offline, your computer will use the fallback fonts.
